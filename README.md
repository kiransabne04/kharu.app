# Kharu website

Static HTML, CSS, and JavaScript for [kharu.app](https://kharu.app), hosted on Vercel. GitHub stores the source. There is no build step.

Privacy: https://kharu.app/privacy.html  
Data deletion: https://kharu.app/delete-data.html

Deploy this repository to Vercel as an **Other** framework project with the repository root as its root directory and no build command. Add `kharu.app` and `www.kharu.app` to the project. At Namecheap, replace only the parking `@` A record and `www` CNAME with the exact values shown in Vercel's domain settings; preserve MX and SPF/TXT records.
